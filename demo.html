02 / System design

How it works

Producer → FastAPI → PostgreSQL → Worker

Correctness boundary

At-least-once delivery. Unique lease tokens fence stale acknowledgements; handlers must make external side effects idempotent.

Path to scale

Scale workers with SKIP LOCKED. Index ready jobs. Partition or archive history as volume grows.

Demo scope

This hosted demo invokes bounded worker ticks during a request. The repository includes standalone continuously polling workers.
